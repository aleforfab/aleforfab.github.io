Markov-chain market model

Markets are usually described as a sequence of regimes (bullish, bearish, stagnant) rather than a smooth curve. This project treats that description as a state machine and asks what the mathematics says about where it settles.

Year
2025
Format
Applied mathematics & quantitative analysis project
Tools
Python · MATLAB
Focus
Linear algebra, spectral analysis, convergence

The question

If the market can be in a small number of states, and if the probability of moving between them depends only on the current state, then the whole system is a discrete-time Markov chain. That buys a strong claim: the long-run behaviour is determined not by history but by the transition matrix alone.

The project builds that chain, propagates it forward one step and many steps at a time, and then checks whether the distribution settles into a stable shape, and how fast.

Approach

  1. 01

    Define the state space

    Three regimes (bullish, bearish, stagnant) encoded so that a daily or weekly observation maps onto exactly one state.

  2. 02

    Build the transition matrix

    One-step probabilities estimated from observed transitions, then raised to powers to get multi-step probabilities. Every row sums to one.

  3. 03

    Find the stationary distribution

    The left eigenvector at λ = 1 gives the long-run share of time spent in each regime, the fixed point of the chain.

  4. 04

    Test the assumptions

    Irreducibility (every state reachable from every other) and aperiodicity are what make that limit meaningful; convergence is then verified numerically.

The maths

For a row-stochastic matrix P, the distribution after n steps is π₀ Pⁿ. The stationary distribution π is the left eigenvector associated with the dominant eigenvalue, and it satisfies πP = π, with components summing to one.

Transition matrix

P = [ pBB pBS pBR ;
      pSB pSS pSR ;
      pRB pRS pRR ]

Rows sum to 1. Subscripts read “from → to”.

Stationary condition

π P = π,  Σπi = 1

Solved as the eigenproblem at λ = 1, then normalised.

Long-run behaviour

limn→∞ π₀ Pn = π

Holds for an irreducible, aperiodic chain.

What the analysis yields

  • A stationary distribution: the share of time the chain spends in each regime over the long run, independent of the starting state.
  • Multi-step forecasts: Pⁿ gives the probability of ending in each regime after n periods.
  • Convergence behaviour: how quickly π₀ Pⁿ approaches π, verified numerically rather than assumed.
  • A stated set of assumptions: irreducibility and aperiodicity are conditions, not decoration; the model is only as good as they are.

The honest limit of any regime model is worth stating plainly: a Markov chain reproduces the transition structure you estimated, so the memoryless assumption is doing a lot of work. The value is in the framework and the convergence analysis, not in a market forecast.
