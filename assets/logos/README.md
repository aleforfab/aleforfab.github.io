# Issuer marks

Single-colour SVG marks used in front of each certification. They are flattened to
the site's `--text-soft` value (`#d6dee9`) so nine cards do not become nine brand
palettes, and every viewBox is cropped to the artwork.

| File | Issuer | Source |
| --- | --- | --- |
| `ansys.svg` | Ansys | Simple Icons (CC0), wordmark |
| `mathworks.svg` | MathWorks | CoreUI Icons (CC BY 4.0) |
| `ptc.svg` | PTC | Wikimedia Commons `PTC logo.svg` (PD-textlogo) |
| `ibm.svg` | IBM | CoreUI Icons (CC BY 4.0) |
| `anthropic.svg` | Anthropic | Simple Icons (CC0) |
| `google.svg` | Google | Simple Icons (CC0) |

All marks are trademarks of their owners and are used here only to identify the
issuer of a completed course. Nothing here implies endorsement.
